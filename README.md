# LiveDrive

LiveDrive is an open-source weather synchronization project for Euro Truck Simulator 2 and American Truck Simulator.

The goal is to synchronize in-game weather with real-world weather using live APIs while preserving smooth transitions and compatibility with the game's native weather system.

## Features (Planned)

- Real-world weather
- Automatic location detection
- Smooth weather transitions
- Open-source
- ATS support
- ETS2 support
